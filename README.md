# Weather Application

This is a simple weather application built using HTML, CSS, and JavaScript. It allows users to search for a city and retrieve the current weather information.

## Features

-   **City Search:** Users can enter the name of a city to get its weather details.
-   **Weather Details:** The application displays the temperature, description, humidity, and wind speed.
-   **Weather Icon:** A weather icon is shown to visually represent the current weather condition.
-   **Error Handling:** Provides a user-friendly message when weather data cannot be retrieved.

## Technologies Used

-   HTML
-   CSS
-   JavaScript
-   OpenWeatherMap API

## Usage

1.  Enter the name of a city in the input field.
2.  Click the search button to retrieve the weather information.
3.  The weather details for the specified city will be displayed.
